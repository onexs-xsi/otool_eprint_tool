# 便签模板排版与交互优化日志

日期：2026-08-19
目标（用户要求）：
1. 排版自动适配各种便签大小，并根据便签大小取舍字段。
2. 加分隔线等元素，让便签更规整。
3. 预览默认不选中任何元素（选择框点按后才显示）。
4. 选择框刚好包住文本，而不是默认大小（元素 heightMm 默认 8mm 导致）。

## 现状问题（代码勘察结论）

- `ComponentLabelFactory.create` 先按 25×15 生成再整体缩放：只缩字号/坐标，不做字段取舍，
  小标签挤爆、大标签空旷。
- 文本元素 `heightMm` 用构造器默认 8mm → 选择框/裁切盒与文字脱节。
- `LabelCanvasView.setDocument` 与 5 处调用方默认选中首元素 → 橙色框常驻。
- 字宽估算 0.55em/半角偏乐观 → 长型号在预览中折行溢出（真机截图证实）。
- 分隔线元素类型（TYPE_LINE h/v）预览/缩略图/打印三链路早已支持，模板未使用。

## 改动清单（v1.5.29 候选）

- `ComponentLabelFactory` 重写为按目标尺寸直接排版：
  - 行距 = 可用高度 / 行数；字号 = 行距 × 0.72 填充系数（largeFont ×1.1）。
  - 行距 < 2.0mm 时按优先级丢字段：参数(10) → 品牌(40) → 品类(60) → 立创(70) → 封装(80) → 规格(90)，
    型号(100) 最后保留。
  - 前缀列宽按"参数："实测 + 0.15mm 呼吸位自适应，上限 5.0mm（防长型号被挤进截断）。
  - 边距 0.3mm、列间隙 0.15mm；字宽估算半角 0.6em、粗体 1.05、fit 留 1% 呼吸位。
  - 元素 heightMm = 行距 × 0.95（真实行高，供预览裁切与选择框贴字）。
- 分隔线（`addSeparators`）：前缀/值列竖线 + 首行下横线常驻；行距 ≥2.8mm 再补全行间横线
  （大标签表格化）。线宽 0.15mm。
- `LabelCanvasView`：
  - `setDocument` 不再回退选中首元素；MainActivity(2 处)/ComponentTemplateController/
    EmbeddedScannerController/ElementEditorController 的 `select(first.id)` 全部移除。
  - `calculateElementBounds` 对文本元素用 StaticLayout 实测宽高（右对齐贴右缘、居中贴中线），
    选择框刚好包字。
- 测试：`ComponentLabelFactoryTest` 更新 + 新增 3 例（分隔线存在性、20×10 取舍、40×30 全字段+行间线）。

## 结论

四项需求全部落地并真机验证：任意尺寸自适应排版（行距驱动字号 + 优先级取舍）、
分隔线（竖线常驻，行距 ≥2.8mm 时表格化）、默认无选中、选择框贴字。
预览/缩略图/打印三路共用 LabelDocument 元素流，效果自动一致。
