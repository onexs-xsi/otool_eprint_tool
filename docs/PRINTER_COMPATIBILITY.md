# 打印机兼容与验收

v1.3 支持四种公开打印语言和三种 Android 硬件通道：

| 维度 | 支持 | 说明 |
|---|---|---|
| 打印语言 | ESC/POS、TSPL/TSPL2、CPCL、ZPL | 以整页 1-bit 点阵发送，不依赖打印机中文字库 |
| 经典蓝牙 | RFCOMM / SPP | 设备必须先在 Android 系统设置配对 |
| 低功耗蓝牙 | BLE GATT 串流写入 | 应用内扫描，要求存在可写特征 |
| USB Host | USB Printer Class 或兼容 Bulk OUT | Android 逐设备授权；可选 Bulk IN 回读 |
| DPI | 203、300 | 由设备档案决定，不允许画布单独覆盖 |
| 有效宽度 | 384、576、832、864 点档案 | 打印前强制校验 |

详细设备名称匹配见 `DEVICE_PROFILES_V1.2.md`，协议格式见 `PROTOCOLS_V1.2.md`，v1.3 统一硬件层见 `HARDWARE_V1.3.md`。

## 不在 v1.3 通用支持范围

- USB Serial（CDC/CH340/FTDI 等）、Wi-Fi、NFC；
- 需要厂商账号令牌、授权密钥、专用 SDK 或私有帧的打印机；
- ESC/POS 之外的票据机私有图形命令；
- 标签校准、耗材 RFID 和未公开的厂商逐任务回执；
- 固件升级、切刀、钱箱控制。

## 实机验收等级

| 级别 | 含义 |
|---|---|
| 协议实现 | 编码器有自动测试，生成格式符合公开手册 |
| 通道可用 | Android 能稳定连接并写完完整任务 |
| 单机通过 | 指定型号/固件完成尺寸和单张打印验证 |
| 批量通过 | 连续 50 张无断连、漏行、错位，并记录参数 |

当前 v1.3 达到“协议实现 + 双向通道实现 + APK 静态验证”。未提供真实打印机的型号、固件和测试结果前，不能把任何具体型号标记为“单机通过”或“批量通过”。

## 实机测试用例

1. 40 × 30 mm，单行 ASCII，检查尺寸与方向。
2. 40 × 30 mm，多行中文、粗体和三种对齐。
3. 画布宽度恰好等于档案最大点宽。
4. 超宽画布应被应用阻止，不能截断发送。
5. SPP 安全连接失败时验证兼容回退。
6. BLE 分别验证默认 MTU 23 与协商后 MTU。
7. 连续打印 10 张，再连续打印 50 张。
8. 打印中关闭打印机，确认应用按 1/2/4/8/16 秒退避重连。
9. USB 打印中拔出再插入，确认按 VID/PID 找回端点并恢复零进度任务。
10. 对支持回读的设备分别验证 ESC/POS `DLE EOT` 或 ZPL `~HS`。
11. 任务部分发送后断线，确认不会自动重发造成双印；人工确认后才能重试。
12. 快速双击相同任务，确认十秒幂等窗口内只进入一次队列。
13. 切换设备档案后必须强制重新连接。
14. 私有协议设备只能显示风险提示，不能宣称打印成功。
