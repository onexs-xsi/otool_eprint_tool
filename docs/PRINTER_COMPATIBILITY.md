# 打印机与驱动支持矩阵

> 2026-10-24 源码发布整理：内置授权令牌与默认授权开关已移除，旧配置不再读取；当前只保留用户明确提供的自定义令牌。下文较早的计划和验证记录属于历史背景，不代表仍分发内置授权数据。

最后梳理：2026-08-18。本文是当前主线的兼容性事实来源；“代码存在”不等于“某台打印机已经兼容”。

## 支持等级

| 等级 | 含义 |
|---|---|
| 编码已实现 | 编码器或解析器有 JVM 自动测试，只证明字节结构和边界行为 |
| 通道已实现 | Android 已具备连接、分包写入及可用时的回读能力，未绑定具体机型结论 |
| 真机已验证 | 指定型号、固件、通道和纸张完成过实际打印；结论不能外推到同系列其他设备 |
| 实验性 | 代码和离线测试已存在，但默认关闭，尚未在目标真机上复验 |
| 未实现 | 当前没有完整的 Android 入口或传输/协议闭环 |

## 协议与驱动

| 协议/驱动 | 编码 | 主动状态 | SPP | BLE GATT | USB Bulk | 真机结论 |
|---|---|---|---|---|---|---|
| ESC/POS | `GS v 0` 整页点阵，已测试 | `DLE EOT` | 通道已实现 | 通道已实现 | 通道已实现 | 仓库内没有具体型号实打记录 |
| TSPL/TSPL2 | `BITMAP`，已测试 | 未接主动查询 | 通道已实现 | 通道已实现 | 通道已实现 | 仓库内没有具体型号实打记录 |
| CPCL | `CG`，已测试 | 未接主动查询 | 通道已实现 | 通道已实现 | 通道已实现 | 仓库内没有具体型号实打记录 |
| ZPL | `^GFA`，已测试 | `~HS` | 通道已实现 | 通道已实现 | 通道已实现 | 仓库内没有具体型号实打记录 |
| 德佟 P1 私有协议 | 0x1F 帧、原始行、流控及回执 | `0x77` 流控、`0x70` 完成回执、配置回读 | 代码路径存在 | **真机已验证** | 档案禁用 | 仅 `P1-现场测试机`、203 DPI、384 点、BLE、25 × 15 mm 基线通过 |

公开协议的档案名称是候选匹配规则，不是型号认证清单。USB 实现是 Printer Class 或兼容设备的 Bulk OUT/Bulk IN，不是 CDC、CH340、FTDI 等 USB Serial 驱动。

## P1 驱动边界

默认路径保留 2026-08-17 的真机基线：未压缩 `0x2B` 位图行、不发送 `0x9E` 授权、不写电机/语言实验参数。连接后必须同时回读 203 DPI、384 点和 `0x77` 缓冲许可才允许打印。

| 能力 | 当前状态 | 默认行为 |
|---|---|---|
| Microchip Transparent UART | BLE 真机已验证 | 优先写 `49535343-8841...`，通知 `49535343-1E4D...` |
| FF00 服务 | 逆向规则已接入，未实机验证 | `FF02` 写、`FF01` Notify；`FF03` 只作可选 credit 通知，不作为写特征 |
| FFE0 服务 | 逆向规则已接入，未实机验证 | `FFE1` 写/通知 |
| 设备信息 180A | 已实现 | 串行读取 2A24、2A28；超时只放弃诊断读取，不阻断连接 |
| 字节/位 RLE、异或、重复行 | 编码和测试已实现，未实机验证 | 默认关闭；压缩结果膨胀时回退原始行 |
| 0x9E/0x9F 离线授权 | 已实现，未实机验证 | 默认关闭；仅显式选择内置密钥或填写自定义令牌时启用 |
| 电机模式、语言写入 | 已实现，未实机验证 | 默认只离线保存，不向设备下发 |
| 份数、边距、旋转、翻转、反色 | 位图变换已实现，未实机验证 | 高级任务选项；任务级对齐因缺少独立目标画布宽度未开放 |
| 厂商/耗材信息 | `0x40` 子类型 4 解析已实现 | 仅在设备实际上报时展示；`0x84` 不是耗材信息块 |
| NFC 信息 | 只有载荷解析器 | Android NFC/NDEF 路由未接入 |
| 设备名通道/DPI 解析 | 只有离线解析器 | 尚未接入发现与自动通道选择；表 `{305,180,203,300,600}` 表示 DPI |

P1 的 SPP 档案仍用于后续验证，但当前实测证据只有 BLE。其他 WePrint、DP、D11、DUAL/LSPP、16/303 等名称或分支不能据此宣称可打印。

## 项目功能闭环

| 层次 | 已有能力 | 边界 |
|---|---|---|
| 标签输入 | 离线二维码/条形码识别、文本解析、毫米画布和文本编辑 | 不含云模板、OCR 或账号服务 |
| 点阵管线 | 按档案 DPI 渲染、1-bit MSB-first、超宽阻止 | 档案参数错误会直接造成尺寸错误 |
| 发现与选择 | 合并 USB、已配对 SPP、BLE；名称/UUID/历史评分；用户确认后连接 | 未知设备不自动认定协议；设备名解析不能替代手册 |
| 连接服务 | 前台服务、任务队列、分包、退避重连、十秒幂等、部分发送后禁止自动重打 | “字节写完”不等于“纸张打印成功” |
| 双向状态 | SPP 输入流、BLE Notify/Indicate、USB Bulk IN；ESC/POS、ZPL、P1 解析 | TSPL/CPCL 尚无主动状态闭环 |
| 配置持久化 | 按物理端点保存协议档案和硬件参数 | 高级 P1 参数不代表真机能力 |

## 明确未支持

- Wi-Fi/TCP、LPD、厂商云打印；
- USB Serial（CDC/CH340/FTDI 等）；
- DUAL/LSPP 自动选路、Android NFC 碰一碰连接；
- P1 之外的德佟/WePrint 型号认证、16/303 专用路径；
- 固件升级、耗材写入、账号令牌获取、切刀和钱箱控制；
- 任意协议或型号的 50 张批量稳定性认证。

## 提升真机等级所需记录

每个“型号 × 固件 × 通道 × 协议”组合至少记录：设备标识、GATT/USB 端点、DPI/点宽、纸张、1/10/50 张结果、断线恢复、状态回读、推荐分包与节流。发生部分发送后必须人工判断是否重打，避免双印。

P1 已有基线证据见 `VALIDATION_V1.4.md`；档案映射见 `DEVICE_PROFILES_V1.2.md`；字节格式见 `PROTOCOLS_V1.2.md`。
