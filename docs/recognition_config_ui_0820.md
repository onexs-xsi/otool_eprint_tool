# 识别配置标签页重构与验证记录

日期：2026-08-20

目标版本：EPrint v1.5.39 / versionCode 45（基线 v1.5.38 / 44）

后续增强版本：EPrint v1.5.41 / versionCode 47（Qwen 可编辑配置与明显错误修正）

状态：v1.5.39 折叠重构与 v1.5.41 Qwen 配置增强均已完成并部署验证

## 1. 改造目标

原标签识别配置将总开关、图像预处理、融合策略、GLM 实验项、GLM 运行参数及 Qwen 状态
连续平铺，常用项与高级项难以区分。此次仅重构展示和交互，不迁移或重命名既有
`RecognitionSettings` / `VlmSettings` 持久化字段，覆盖安装后继续使用原配置。

## 2. 已完成实现

- 标签页拆成 6 个独立折叠区：识别流程、图像预处理、结果整理与融合、GLM 输入实验、
  GLM-OCR 运行参数、Qwen3.5 text-only 状态。
- 主界面入口由“模型配置”统一命名为“识别配置”，标签/二维码/条形码禁用提示同步更新。
- 常用的前三组默认展开，高级/实验/只读模型状态默认折叠；每组展开状态写入独立 UI
  SharedPreferences，不会触发识别配置保存。
- 新增“全部展开”“全部折叠”“恢复推荐值”。恢复推荐值同时覆盖标签识别与 GLM 运行参数，
  但只修改当前对话框，仍需点击“暂存配置”或“保存并重启”后才生效。
- 新增依赖联动：关闭标签总开关后禁用从属控件；融合权重仅在 PP-OCR 与 GLM-OCR
  同时启用时可调；弱码条纹定位必须先启用 GLM 码区遮盖。
- 校验失败时临时展开所有可编辑分组，避免错误字段藏在折叠区；Qwen 在 v1.5.39 阶段保持只读。
- GLM 状态说明与真实链路对齐：默认是全文转写后规则提取，只有包含完整七键 schema 的
  自定义提示词才进入 JSON 提取。

## 5. v1.5.40-v1.5.41 Qwen 配置增强

- Qwen 折叠区已从只读部署状态扩展为独立可编辑配置：启停、仅核心字段缺失时调用、目录强校验、
  CPU 线程、最大输出 Token、超时和额外 text-only 规则。
- v1.5.41 新增 `允许 Qwen3.5 修正明显错误（需 OCR/格式/目录证据，默认关闭）`。开启后会
  检查字段完整的记录，并自动关闭、禁用 `仅在核心字段缺失时调用`；设置对象在持久化层也会
  归一化这组互斥关系，旧配置不会形成“开了纠错却被提前跳过”的状态。
- 纠错不等于自由覆盖：当前值必须在本次 OCR 中无证据、可证明误取内部/订单/跟踪/批次或其他
  语义字段，或目录值非法；候选必须来自独立 OCR 行并通过格式和可选目录校验。型号还会硬拒绝
  品牌、品类、规格、封装等已知非型号值。
- 真机 UI 验证确认开启纠错后“仅缺失时调用”立即取消勾选并置灰；对话框随后取消，未保存测试值，
  临时折叠偏好已清除。截图：`artifacts/eprint-v1.5.41-qwen-correction-config.png`。
- v1.5.41 全量门禁为 229 项 JVM 单测全过、Lint 0 error / 388 warning；最终 APK 已安装到
  SM-X800，并通过真实 Qwen3.5-2B 明显错误修正及全请求 `vision=0us` 回归。
