# v1.3 横屏平板主界面

## 布局基准

v1.3 以横屏 Android 平板作为默认操作设备。`activity_main.xml` 的横屏资源使用水平权重 `1 : 2`：

| 左侧 1/3 | 右侧 2/3 |
|---|---|
| 常驻摄像头取景 | 当前打印机、连接状态与诊断 |
| 二维码 / 条形码双模式连续识别 | 指定毫米尺寸的标签画布 |
| 扫码原文 | 设备档案、DPI 与画布尺寸 |
| 本机结构化解析摘要 | 文本编辑、预览和打印任务控制 |

左侧操作条由“启动/暂停摄像头”和一个双态滑块组成。滑块的“二维码 / 条形码”文字均位于轨道内部，橙色滑块表示当前模式；切换后解码器立即换用互斥格式集合，不再保留“再次放入画布”。二维码模式只接收 QR，条形码模式接收 Code 128/39/93、EAN-13/8、UPC-A/E、ITF 和 Codabar。

内容进入取景框后，应用会去重同一连续结果，在设备上解析并自动写入右侧当前文本元素。整个过程不需要 `INTERNET` 权限。

## 方向策略

- `MainActivity` 请求 `sensorLandscape`，允许设备使用正向或反向横屏；
- 面向 API 36 声明 `PROPERTY_COMPAT_ALLOW_RESTRICTED_RESIZABILITY`，用于当前专用平板的临时兼容模式；
- Android 17 / API 37 起，大屏系统可能始终忽略固定方向请求，因此保留基础竖屏资源以避免功能中断；
- 产品验收、视觉调整和现场操作说明均以横屏 1:2 界面为基准。

## 已验证主机

Samsung SM-X800、Android 14 / API 34：窗口 2800 × 1752、rotation 90；嵌入相机预览、左右分区、画布和打印机控制同时可见，启动日志无致命异常。
