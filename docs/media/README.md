# README 视觉素材

`eprint-hero.png` 是项目首页的使用场景示意图，基于 EPrint v1.5.42 / versionCode 48 在 SM-X800 上运行时的 ADB 截图制作。

- 实际运行当前源码构建，使用临时的合成器件字段生成标签预览。
- 使用内置 ImageGen 工具编辑摄像头区域为卡通元器件场景，并填充底部示例结果；保留实际应用布局、版本与未连接状态。
- 图片中的字段不是本次摄像头 OCR 的实测结果，截图过程中没有触发实体打印。
- 摄像头实景、设备地址、原始偏好备份和未处理截图均不随仓库分发；示例完成后恢复设备原有偏好。
- 提示词见 [`eprint-hero.prompt.txt`](eprint-hero.prompt.txt)。图片通过 README 中的仓库相对路径引用，无需外部图片托管。

本图用于说明工作流程，不能作为机型兼容、识别准确率、性能或实际打印效果的验收证据。
