> 2026-10-24：公开源码不分发分类种子或合并目录快照。以下为本机历史同步与验证记录，不构成数据再分发许可；当前可选导入和缺失回退见 [构建说明](BUILDING.md)。

日期：2026-08-20

目标版本：v1.5.36 / versionCode 42

## 1. 目标与结论

在 Qwen3.5 结构化补全之前，先提供不依赖大模型、可解释、可离线工作的基础路径：

1. 从立创商城公开电子元器件目录取得末级品类及中英文名称；
2. 对每个品类读取公开的“品牌”和“封装/规格”筛选数据；
3. 构建 APK 内置的品类—品牌—封装单一快照；
4. PP-OCR 解析时用目录规范品类和品牌，并只允许该品类集合中的封装候选落入“封装”字段；
5. 双通道冲突时可让目录命中显著提高品类、品牌、封装权重，型号、规格和料号仍遵循普通融合档位；
6. 目录无法匹配或快照加载失败时保留原始 OCR/基础正则回退。

## 2. 数据来源与访问边界

- 目录来源：<https://www.szlcsc.com/catalog.html>
- 分类页示例：<https://list.szlcsc.com/catalog/439.html>
- 参数数据：分类页自身调用的 `POST https://list.szlcsc.com/parameter`，仅取 `queryProductGradePlateId`（品牌）和 `queryProductStandard`（封装/规格）。
- 目录范围：排除 `mainCategoryCode=mro`，只保留电子元器件末级品类。
- `https://list.szlcsc.com/robots.txt` 允许 `/` 和 `/catalog/*.html`；同步脚本只读取公开筛选参数，不登录、不绕过验证码、不抓商品详情。
- 立创另有需要申请密钥的官方开放 API：<https://lcsc.com/agent>。当前快照不依赖账号或私有密钥；若后续获得正式 API 授权，应优先迁移同步数据源。

应用清单仍不申请网络权限。商城访问只发生在开发期同步脚本中，用户设备识别时只读取 APK 资产。

| 文件 | 用途 |
|---|---|
| `tools/lcsc/electronic_categories.json` | 479 个公开电子元器件末级品类快照 |
| `tools/lcsc/sync_package_catalog.py` | 限速、重试、可续传的品牌/封装参数同步器 |
| `apps/android/app/src/main/assets/catalog/lcsc_category_packages.json` | 合并的 Android 运行时离线索引（兼容保留原文件名） |
| `CategoryPackageMatcher.java` | 纯 JVM 品类、品牌别名和品类约束封装匹配规则 |
| `LcscPackageCatalog.java` | 后台延迟加载 APK 资产 |

刷新命令：

```powershell
python tools/lcsc/sync_package_catalog.py --workers 2 --delay-ms 400 --refresh
```

脚本默认每 400 ms 最多启动一个请求、并发数 2，失败指数退避并最多重试 4 次。每个品类只缓存提取后的品牌和封装数组，`tools/lcsc/cache/` 不进入 Git；中断后去掉 `--refresh` 即可续跑，正式更新快照时保留 `--refresh`。只有全部品类成功时才替换最终资产。

## 4. 匹配规则

1. 品类按末级中英文名称匹配；完整名称优先于包含关系，有多个同级候选时拒绝猜测。
2. OCR 只给出上级/泛化品类时，使用同父级或根目录规则的并集。
3. 封装候选只接受独立 OCR 行，或带 `封装:` / `Package:` / `Pkg:` 前缀的整值。
4. 不在型号长串中做子串搜索，例如 `CGA0402C0G120J500GT` 不会产生封装 `0402`。
5. 已匹配到目录品类时，旧全局正则无权回填不属于该品类的四位数字。
6. 品牌支持规范全名、括号前英文名和括号内中文别名；品类已知时还要求品牌存在于该品类集合。
7. “立创字典命中时显著提高品类/品牌/封装权重”是可持久化选项，默认开启；只有一侧命中目录时才越过全局 OCR 权重，两侧都命中但内容不同仍按原融合档位取舍。
8. 未命中字典的字段保持原始 OCR 取舍，不会因字典缺项而被清空。

PP-OCR 和 GLM 全文转写均复用同一个匹配器；GLM 信息提取模式则继续通过同图 PP-OCR 证据补齐和校验字段。未来 Qwen3.5 应位于此确定性路径之后，只补缺失字段，并对目录冲突给出候选而不是覆盖可验证结果。

## 6. 已知边界

- 快照检索时间为 2026-08-20 04:21:42（Asia/Shanghai）；商城新增品类、品牌或封装后需重新同步并发版。

- 品牌字典只证明“该写法是目录品牌且属于当前品类”，不能在两个都合法但互相冲突的品牌之间替代视觉证据。
