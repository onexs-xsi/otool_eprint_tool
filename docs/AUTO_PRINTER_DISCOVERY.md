# 自动寻找打印机

v1.3 的“自动找打印机”会在一个流程中合并三类端点：

1. USB Host 上具备 Printer Class 或 Bulk OUT 的设备；
2. Android 系统已经配对的经典蓝牙 SPP 设备；
3. 应用在 10 秒内扫描到的附近 BLE 设备。

## 识别依据

每个候选设备会在本机评分：

| 依据 | 作用 |
|---|---|
| 上次成功连接的地址、通道和档案 | 最高排序优先级；仍需用户点击确认，不自动连接 |
| USB Printer Class / Bulk OUT | 标准打印类强加分；通用 Bulk OUT 仅作为待确认候选 |
| 已知设备名称族 | 匹配 POS58/POS80、TSC、Zebra 等内建档案 |
| 已确认设备身份 | `P1-数字序列` 识别为德佟电子 P1 系列、203 DPI、384 点/48 mm；协议独立判断 |
| 蓝牙 Major Device Class | 成像设备加分，音频、手机、电脑、穿戴设备减分 |
| Bluetooth Rendering Service | 声明渲染能力的经典设备加分 |
| BLE 广播服务 | FFE0、FF00、18F0 等常见串流打印服务加分 |
| 名称关键词 | Printer、Thermal、Label、POS、品牌词等加分 |
| RSSI 与配对状态 | 作为弱辅助依据，不单独判定打印机 |

耳机、音箱、手表、键盘、鼠标、手机和电脑会被主动降权。全部判断和历史记录只保存在设备本机。

## 发现与连接规则

- 点击“自动找打印机”只枚举、识别和排序，不会连接任何新候选。
- 即使只有一个高可信候选或发现上次设备，也必须由用户点击该项并在详情页确认。
- 详情页显示名称、地址、通道、信号、制造商、规格、识别依据、拟用档案和私有协议风险。
- 用户确认后才写入“持续连接意图”并建立通道。
- 已经由用户选定的设备发生断线时，服务自动恢复同一端点；这属于重连，不是重新自动选择设备。
- USB 断线后按 VID/PID 等待同一设备重新接入；蓝牙按已选地址重连。
- 用户可以切换到“显示全部设备”手动模式。
- 疑似私有协议设备即使设备身份可信，也不会绕过风险确认。

## 能做与不能做

自动发现能够尽量找出“哪一个蓝牙设备像打印机”，并为已知名称族建议协议档案；但蓝牙标准没有统一的“打印语言”能力字段。未知 OEM 设备即使具备可写 GATT 特征，也无法在不发送潜在副作用命令的情况下百分之百判断其使用 ESC/POS、TSPL、CPCL、ZPL 还是私有协议。

因此首次连接未知设备仍需根据机身型号、配置页或说明书确认档案。用户选择后应用会记住该端点，并以 1、2、4、8、16 秒退避持续重连；16 秒为最大间隔而不是最大次数，只有点击“手动断开”才清除连接意图。
